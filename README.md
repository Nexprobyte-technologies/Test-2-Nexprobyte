## 🎨 Architectural Design System & Reverse-Engineered Features

### 1. Visual Styling & Fidelity
- **Typography**: Precision typography matching Framer's aesthetic using Google Fonts `Inter Display`, `Inter`, and `Geist Mono` for metrics and monospaced badges.
- **Glassmorphic Floating Dock**: Fixed floating navigation pill with `backdrop-filter: blur(20px)`, hover pill highlight, and interactive multi-column service dropdowns.
- **ScrollSpy Active Highlighting**: Real-time section detection dynamically highlighting active navigation links during scrolling.
- **Micro-Interactions**: Custom cubic-bezier spring curves (`cubic-bezier(0.16, 1, 0.3, 1)`), button scale on hover, icon translation, and glowing radial mesh backgrounds.
- **Responsive Parity**: Complete responsive behavior across Desktop (`>=1200px`), Tablet (`810px - 1199px`), and Mobile (`<810px`) viewports with a dedicated slide-in drawer.

### 2. Interactive Components & State Machines
- **Live Operational Stream**: Real-time ticker simulating live completed tasks from VAs and dev teams (auto-injects new items every 4.5 seconds).
- **Interactive AI Copilot Playground**: Switch between lead qualification, 24/7 autonomous support bot, and sprint velocity analytics with live simulated metrics.
- **Interactive 5-Tab Ecosystem Tour**: Deep dive into all 5 company pillars with rich, responsive UI mockups:
  1. *Virtual Assistance* (Inbox zero, calendar coordination, real estate CRM data entry)
  2. *Software Development* (Active sprint commits, PR review turnaround, TestFlight deployments)
  3. *AI & Automations* (Visual n8n execution nodes, WhatsApp Business integration)
  4. *Web & E-Commerce Support* (99/100 PageSpeed scores, Shopify SKU management, security)
  5. *Custom Software & ERP* (Live billing console, automated invoice settlements)
- **Cost Savings & ROI Calculator**: Real-time slider (1-10 specialists) and role selector comparing US/EU in-house hiring costs ($120k+) against dedicated Nexprobyte pods ($30k+), showing up to 75% savings ($180,000+/year) with smooth number counter animation.
- **3D Talent Card Customizer**: Interactive 3D mouse tracking tilt physics with dynamic specular glare, color theme customizer (Obsidian, Cobalt, Emerald, Nebula), and instant role profile switching.
- **Working Monthly / Annual Pricing Toggle**: Dynamic switcher recalculating annual discount savings (Save 20%) across Starter, Growth, and Enterprise tiers.
- **Dual-Group Infinite Marquees**: Seamless mathematical loop for partner brands and client testimonials without stutter or snap jumps.
- **Animated Accessible FAQ Accordion**: Fluid height transitions with `aria-expanded` attributes and rotating chevrons.
- **Interactive Discovery Call Form**: Form validation, dynamic loading state on submit, and toast confirmation modal.
