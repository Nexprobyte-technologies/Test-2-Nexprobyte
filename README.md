# Nexprobyte Technologies - Next.js Web Application

A clean-room, pixel-accurate reverse engineering of the high-end fintech Framer template (`https://sarofinance.framer.website/`) and complete integration of **all content from `https://test-nexprobyte.vercel.app/`**, built with **Next.js (App Router)** and **Framer Motion**, tailored specifically for **NEXPROBYTE TECHNOLOGIES** incorporating 100% of all 52 core services from the attached company specification alongside all 8 core disciplines, case studies, Tamil Nadu testimonials, industries, and technical insights.

---

## 🚀 Live Preview & Execution

### 1. Development Server
Run the Next.js development server:
```bash
npm run dev
```
Then navigate to: [http://localhost:3000](http://localhost:3000)

### 2. Production Build
Compile the optimized production application:
```bash
npm run build
```
Outputs static bundle with Next.js App Router pre-rendering to `.next` and `out/`.

### 3. Production Server
Run the Next.js production server:
```bash
npm start
```

### 4. Direct Static Access / Local Server
Double-click `index.html` or run:
```bash
npm run serve
```

## 🎨 Architectural Design System & Reverse-Engineered Features

### 1. Framework & Motion
- **Next.js App Router**: Modern `app/` directory architecture (`app/layout.jsx`, `app/page.jsx`, `app/globals.css`).
- **Framer Motion (`framer-motion`)**: Layout springs (`layoutId="nav-pill"`), dropdown animations, spring drag physics.
- **Hero Hanging Threads (7 Suspended Squircles)**: 7 clean hanging cords framing the headline without any bulky top box or capsule (hanging directly from the ceiling), carrying 3D glossy squircles with real developer & tech stack icons:
  - 0: Royal Violet / Indigo (ERP, BI & Dashboards)
  - 1: Dark Obsidian (React Atom - Full-Stack Developers)
  - 2: Vibrant Orange (AI Sparkle - AI Automation & Agents)
  - 3: Mint Emerald (Smartphone / Flutter - Top 1% Virtual Assistants)
  - 4: Electric Green (Code `</>` - Dedicated Dev Teams)
  - 5: Cobalt Blue (AWS Cloud - DevOps & Cloud APIs)
  - 6: Lime Green (Shopify Bag - E-Commerce Management)
  - Featuring real-time Bezier tension curve physics, ambient sinusoidal sway, mouse cursor parallax, and drag & spring release.
- **Glassmorphic Floating Dock**: Fixed floating navigation dock with backdrop blur, sliding hover pill indicator across nav links, scroll morph elevation, spring dropdowns, and mobile drawer.
- **Content Integrity**: All 52 PDF service items from Nexprobyte Technologies preserved 100% verbatim.
- **Branding**: Official Nexprobyte logo (`/assets/logo-transparent.png`) in navbar, drawer, footer, and favicon.

### 2. Interactive Components
- **Real-Time Operational Stream**: Auto-injecting live operational event ticker.
- **Interactive AI Copilot Playground**: Switch between lead qualification, 24/7 autonomous support bot, and sprint velocity analytics with live simulated metrics.
- **Interactive 5-Tab Ecosystem Tour**: Deep dive into all 5 company pillars with rich, responsive UI mockups.
- **Cost Savings & ROI Calculator**: Real-time slider and role selector comparing in-house costs against dedicated Nexprobyte pods with smooth number counter animation.
- **3D Talent Card Customizer**: Interactive 3D mouse tracking tilt physics with dynamic specular glare, color theme customizer (Obsidian, Cobalt, Emerald, Nebula), and instant role profile switching.
- **Monthly / Annual Pricing Toggle**: Dynamic switcher recalculating annual discount savings (Save 20%) across Starter, Growth, and Enterprise tiers.
- **Dual-Group Infinite Marquees**: Seamless mathematical loop for partner brands and client testimonials.
- **Animated Accessible FAQ Accordion**: Fluid height transitions with `aria-expanded` attributes and rotating chevrons.
- **Interactive Discovery Call Form**: Form validation, dynamic loading state on submit, and toast confirmation modal.
